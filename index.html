01 / The problem

Research needs guardrails.

Fast experiments can produce fragile conclusions. The project brings common sources of backtest error into the workflow so assumptions are easier to inspect.

01

Reproducibility

Notebook steps, reusable modules, and tests make it easier to trace how data becomes a result.

02

Look-ahead risk

Forward-return and triple-barrier labeling are separated from current features to help preserve time order.

03

Signal evaluation

Information coefficient helpers and model pipelines offer ways to assess a signal beyond its chart.

04

Trading friction

The backtesting engine models configurable commission and slippage when positions change.

05

Risk context

Return, drawdown, volatility, Sharpe, Sortino, VaR, and expected shortfall metrics add context to a run.

06

Inspectable workflow

Python modules, tests, and five ordered notebooks make the research path easier to follow and adapt.

05 / Code example

Generate a starter feature set.

This is the repository's `add_basic_indicators` helper in use; the OHLCV input should include open, high, low, close, and volume.

import pandas as pd
from src.indicators import add_basic_indicators

prices = pd.read_csv("prices.csv", parse_dates=["date"])
prices = prices.set_index("date")

features = add_basic_indicators(prices)
print(features[["close", "rsi_14", "macd"]].tail())

What it adds

The helper in src/indicators.py asks stockstats to calculate moving averages, MACD, RSI, ROC, Bollinger data, stochastic values, ATR, CR, Williams %R, and log returns, then returns a pandas DataFrame.

See the function and its validation tests before adapting the feature set to your own dataset.

Indicator columns can contain warm-up NaNs. Inspect and handle those rows before modeling or comparing strategies.
06 / Getting started

Run it locally.

Python 3.10+ is declared by the package metadata. The project includes editable-install and requirements-based setup paths.

Start with the module tests, then open the dashboard. Market-data loading uses yfinance and requires network access.

Read the quick start ↗
01
Clone

Get the source and enter the repository.

git clone https://github.com/aitelkob/stockstats-alpha-lab.git
cd stockstats-alpha-lab
02
Install

Install package dependencies (or use `pip install -r requirements.txt` for the dashboard set).

python -m pip install -e .
03
Run tests

Execute the repository's pytest suite.

python -m pytest tests/
04
Launch the dashboard

Start the Streamlit application in your browser.

streamlit run streamlit_app.py
